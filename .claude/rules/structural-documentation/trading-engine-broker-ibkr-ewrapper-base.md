## `EWrapperAbstractBase`

`public abstract class EWrapperAbstractBase implements EWrapper`

### 1. Class/Interface Responsibilities

Implements every method of the `com.ib.client.EWrapper` interface with an empty body so a subclass overrides only the callbacks it uses.

### 2. Injected Dependencies

None. The class declares no constructor and no fields.
